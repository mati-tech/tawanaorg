# Foundation Website (V1)

Static multilingual Flutter Web site for an international charity foundation.

## Languages
- English (en, LTR)
- Russian (ru, LTR)
- Persian/Dari (fa, RTL)
- Pashto (ps, RTL)

## Requirements
- Flutter 3.35+
- Dart 3.9+ (see `environment.sdk` in pubspec.yaml)

## Setup
```bash
flutter pub get
flutter gen-l10n
flutter run -d chrome
